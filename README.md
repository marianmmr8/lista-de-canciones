# Mi lista de canciones

Aplicacion web sencilla para consultar y gestionar una lista de canciones.

## ¿Qué hace?

- Muestra las canciones disponibles en una lista numerada.
- Indica cuantas canciones hay en total.
- Permite añadir una nueva cancion usando el formato `Titulo - Artista`.
- Permite buscar canciones introduciendo texto en el campo de busqueda.

## Uso

Abre `intex.html` en un navegador. A continuación, podrás escribir el nombre de una cancion en el campo correspondiente y añadirla a la lista.
